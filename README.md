# دو پیشنهاد طراحی برای پلتفرم دیجیتال کافه‌رستوران

صفحه ارائه و مقایسه دو کانسپت «روشن و آرام» و «دارک و گرم» برای کافه‌رستوران.
این پروژه فقط یک صفحه استاتیک نمایش تصاویر است؛ بک‌اند، ثبت‌نام، پیامک، رزرو واقعی،
سفارش‌گیری یا پرداخت ندارد.

## اجرای محلی

```bash
npm install
npm run dev      # سرور توسعه
npm run build    # خروجی production در پوشه dist
npm run preview  # بررسی خروجی build
```

مسیر تصاویر در صفحه از `/designs/...` شروع می‌شود؛ Vite هنگام build محتوای `public/` را در
ریشه `dist/` قرار می‌دهد.

### درباره تصویر پنل آشپزخانه در کانسپت دارک

از هشت تصویر خواسته‌شده، هفت تصویر در پیوست‌ها موجود بود. تصویر «پنل آشپزخانه — کانسپت دارک»
ارسال نشده است؛ فایلی که پیش‌تر با همین نام ذخیره شده بود در واقع همان نسخه روشن بود
(میانگین روشنایی ۲۳۸ از ۲۵۵) و به همین دلیل حذف شد. در صفحه، جای این تصویر با یک کادر
هم‌ابعاد و پیام «تصویر این صفحه ارسال نشده است» نگه داشته شده تا چیدمان جابه‌جا نشود و
تصویر سبک دیگر جایگزین آن نشود. پس از دریافت فایل درست:

1. آن را با نام `public/designs/kitchen-dark.png` ذخیره کنید.
2. در `index.html` داخل بخش «پنل آشپزخانه»، در `figure` با `data-design="kitchen-dark"`
   کلاس `shot--missing` را بردارید و به‌جای بلوک `div.shot__media--missing` ساختار تصویر
   و دکمه‌های همان سبک را از بخش دیگر کپی کنید (مانند `kitchen-light`)؛ فقط `src`، `alt`،
   `width`/`height` و `data-open="kitchen-dark"` را مطابق فایل جدید بگذارید.
3. `npm run build` را دوباره اجرا کنید.

## انتشار روی Netlify

**روش دستی (بدون اتصال به Git):** پس از اجرای `npm run build`، پوشه `dist` را در بخش Deploys
پنل Netlify (کادر «drag and drop») رها کنید. فایل آماده `netlify-dist.zip` هم همان محتوای
`dist` است و می‌توان همان را آپلود کرد. ورود یا متغیر محیطی لازم نیست.

**روش اتصال به Git:** فایل `netlify.toml` تنظیمات را تعیین می‌کند:

- Build command: `npm run build`
- Publish directory: `dist`

## نکات

- متاتگ `noindex, nofollow` روی صفحه تنظیم شده و صفحه بدون ورود قابل مشاهده است.
- هر تصویر با ابعاد اصلی و بدون برش (`object-fit` پیش‌فرض) نمایش داده می‌شود.
- تصویر فعال اولیه با `preload` و `fetchpriority="high"` بارگذاری می‌شود؛ بقیه هنگام نیاز.
- محو شدن کوتاه هنگام تغییر سبک/تب/مقایسه اعمال می‌شود و در حالت
  `prefers-reduced-motion: reduce` غیرفعال است.
